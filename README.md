## 🛡️ Incident Response — Quick Notes

- **Alert triage:** Validate whether a security alert is a true positive or a false positive before treating it as an incident.
- **Incident types:** Common categories include malware infection, security breach, data leak, insider attack, and denial-of-service (DoS).
- **SANS PICERL:** Preparation, Identification, Containment, Eradication, Recovery, and Lessons Learned.
- **Core security tools:** SIEM centralizes and correlates logs; antivirus detects known malware; EDR provides endpoint detection and response capabilities.
- **Playbooks vs. runbooks:** Playbooks provide comprehensive incident-response guidance, while runbooks describe detailed execution steps for specific procedures.

These notes are learning summaries and should be adapted to an organization's incident response plan and environment.
